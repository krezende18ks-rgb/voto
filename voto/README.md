# 🗳️ ClassVote

Sistema de votação eletrônica desenvolvido para eleições de representantes de turma, com foco em integridade dos registros, auditoria de votos e rastreabilidade.

## ✨ Funcionalidades
- **Gestão de Eleições e Candidatos:** Cadastro e controle de chapas/candidatos por turma.
- **Votação Segura:** Registro único por eleitor com validação de elegibilidade.
- **Auditoria e Integridade:** Geração de logs/registros auditáveis para verificação dos resultados.
- **Testes Automatizados:** Cobertura de testes unitários e de integração no cliente.

## 🛠️ Tecnologias Utilizadas
- **Frontend:** React / Vite, Vitest
- **Backend:** Node.js
- **Banco de Dados:** PostgreSQL (com scripts de backup e migração)
